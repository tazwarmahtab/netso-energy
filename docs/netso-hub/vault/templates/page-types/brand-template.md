# Brand Page Template

Use this template for in-depth knowledge about a specific brand or competitor's positioning, voice, and strategy.

Brand pages differ from entity pages. Entity pages are factual profiles (pricing, features, timeline). Brand pages focus on how a company positions itself, how it communicates, and where it sits strategically. Create both and link them to each other.

```yaml
---
created: YYYY-MM-DD
updated: YYYY-MM-DD
type: wiki-page
page-type: brand
brand-name: Company Name
source-count: 0
sources: []
related: []
---
```
