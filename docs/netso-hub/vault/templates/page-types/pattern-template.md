# Pattern Page Template

Use this template for recurring trends, behaviors, or structural patterns you observe across multiple sources.

Patterns are one of the highest-leverage page types. A single data point is an anecdote. Three data points showing the same thing across different companies or time periods is a pattern. Patterns drive content angles, positioning shifts, and strategic bets.
