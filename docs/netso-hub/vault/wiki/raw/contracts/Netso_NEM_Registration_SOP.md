# NEM REGISTRATION SOP
## 6-Step Net Metering Registration Process for Bangladesh

---

## OVERVIEW

| Item | Details |
|------|---------|
| **Regulation** | BERC Net Metering Guidelines 2025 |
| **Applicable For** | Rooftop Solar Systems up to 1 MW |
| **Settlement Period** | Quarterly (excess export) |
| **Surplus Rate** | BDT 6.45/kWh |
| **Processing Time** | 30-45 days (typical) |
| **Validity** | As long as system is operational |

## STEP 3: TECHNICAL REVIEW & INSPECTION

### 3.1 DISCO Review Timeline

| Stage | Timeline |
|-------|----------|
| Initial screening | 7-10 days |
| Technical review | 10-15 days |
| Site inspection | 15-20 days |
| Final approval | 5-10 days |
| **Total** | **30-45 days** |

### 3.2 Site Inspection

**Inspector will check:**

| Item | What to Verify |
|------|----------------|
| Roof condition | Structural stability, shading |
| Electrical infrastructure | DB capacity, cable routing |
| Safety measures | Earthing, lightning protection |
| Equipment placement | Inverter location, accessibility |
| Net meter location | Accessibility for reading |

**Preparation for inspection:**
- [ ] Ensure site access
- [ ] Have all equipment on-site
- [ ] Keep documentation ready
- [ ] Netso engineer present
- [ ] Customer representative present

### 3.3 Common Inspection Issues

| Issue | Solution |
|-------|----------|
| DB capacity insufficient | Upgrade DB before inspection |
| No space for net meter | Create dedicated meter space |
| Shading concerns | Provide shading analysis report |
| Cable routing unclear | Mark cable route clearly |

## STEP 4: NET METER INSTALLATION

### 4.1 Meter Specifications

| Parameter | Requirement |
|-----------|-------------|
| Type | Bidirectional (import/export) |
| Accuracy | Class 1.0 or better |
| Communication | Optional (AMR compatible) |
| Certification | BSTI approved |
| Display | LCD with import/export readings |

### 4.2 Installation Process

1. **DISCO issues meter** (after approval)
2. **Netso installs meter** (or DISCO installs)
3. **Meter testing** by DISCO
4. **Meter sealing** by DISCO
5. **Meter reading training** for customer

### 4.3 Installation Checklist

- [ ] Meter installed in accessible location
- [ ] CTs installed correctly (if applicable)
- [ ] Meter tested and calibrated
- [ ] Meter sealed by DISCO
- [ ] Initial reading recorded
- [ ] Customer briefed on reading

## COMMON ISSUES & SOLUTIONS

### Issue 1: Application Rejected

**Possible Reasons:**
- Incomplete documentation
- System over 1 MW
- Outstanding DISCO dues
- Technical non-compliance

**Solution:**
- Review rejection letter carefully
- Address specific issues
- Re-submit with corrections

### Issue 2: Delayed Approval

**Possible Reasons:**
- High application volume
- Incomplete technical review
- Site inspection delays

**Solution:**
- Follow up weekly
- Escalate to senior officers
- Consider using a consultant

### Issue 3: Net Meter Not Reading Export

**Possible Reasons:**
- Meter configuration issue
- CT polarity reversed
- Inverter not exporting

**Solution:**
- Contact DISCO meter department
- Check CT connections
- Verify inverter settings

### Issue 4: Surplus Payment Delayed

**Possible Reasons:**
- DISCO processing delays
- Documentation issues
- Bank details incorrect

**Solution:**
- Follow up with DISCO accounts
- Verify bank details
- Escalate if >60 days
