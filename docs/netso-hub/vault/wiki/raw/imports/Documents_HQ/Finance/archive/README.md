# Finance Archive

Historical models, completed deal files, and superseded data are archived here.

**Rule**: Never delete from this directory. Archive is append-only.

| Directory | Contents |
|:----------|:---------|
| `data/` | Canonical pilot data CSV, import logs |
| `deals/` | Per-rooftop deal model outputs |
| `models/` | Superseded model versions |
| `reports/` | Monthly reports from prior periods |
