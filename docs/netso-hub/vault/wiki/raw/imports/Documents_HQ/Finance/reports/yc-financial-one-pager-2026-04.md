## Revenue Model

Three revenue streams from each rooftop:

1. **Installation margin** — profit on EPC + equipment install (one-time, ~15% margin)
2. **PPA generation revenue** — 25 years of BERC-tariff-backed cash flows from exported electricity
3. **Asset value appreciation** — each commissioned rooftop adds ~$64K to portfolio book value

### Path to Revenue
```
Signed PPA → IDCOL disbursement tranches → Installation complete → SREDA commissioning →
PPA generation revenue begins → Asset on Netso's balance sheet
Timeline: ~8–12 weeks from contract signing to first revenue
```
