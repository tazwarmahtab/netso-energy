## Vetting Checklist (Per Supplier — Before Any Purchase)

- [ ] Authorized distributor (demand authorization letter)
- [ ] Trade license verified
- [ ] SREDA certification copies on file (for every model ordered)
- [ ] Minimum 2 years supplying solar equipment in Bangladesh
- [ ] At least 3 reference installations in Bangladesh
- [ ] Minimum 10-year panel warranty, 5-year inverter warranty confirmed
- [ ] Lead time confirmed in writing
- [ ] Pricing valid for the order quantity
- [ ] AIT on imports included in quotation
