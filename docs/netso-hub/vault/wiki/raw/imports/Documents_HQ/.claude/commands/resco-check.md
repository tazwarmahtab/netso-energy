# resco-check

Check the status of the Netso RESCO registration and regulatory compliance.

## Implementation
1. Scan the `03-Governance-Legal/` directory for the `RESCO_Application_Shell.md`.
2. check which fields are still missing (TIN, NID, Commissioning Date).
3. If the user is present, prompt for these specific items.
4. If fields are complete, offer to generate the final PDF or submission letter.
