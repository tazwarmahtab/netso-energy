# investor-update

Generate a monthly or event-driven update for Netso investors and stakeholders.

## Implementation
1. Aggregate data from `02-Pilot-Proof/` (performance data) and `wiki/entities/Netso.md` (milestones).
2. Format as a professional "VC Verdict" bridge.
3. Highlight:
   - System performance vs. Projection.
   - Pipeline growth (Rooftop acquisition speed).
   - Regulatory progress (RESCO status).
4. Save the draft to `01-Funding-materials/Updates/`.
