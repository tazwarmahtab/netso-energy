# Walkthrough - Netso Hero Section

I have successfully recreated the Hero section of the Netso website as a pixel-perfect match to the provided reference, using the clean background image.

## Features
- **Pixel-Perfect Design**: Matches the typography, spacing, and layout of the reference image.
- **Glassmorphism**: Implemented the floating card with a realistic glass effect.
- **Animations**: Smooth entrance animations for text and the floating card using Framer Motion.
- **Responsive**: Adapts to different screen sizes while maintaining the design integrity.
- **Clean Code**: Built with React, TypeScript, and Tailwind CSS.

## Project Structure
- `src/components/Hero.tsx`: The main hero section component.
- `src/components/Navbar.tsx`: The navigation bar.
- `public/assets/`: Contains the reference and background images.

## How to Run

2. Navigate to the project directory: `cd /Users/tazwarmahtab/Netso_site`
