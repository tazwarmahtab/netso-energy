# NEM Registration Process (Bangladesh)

The 6-step net metering (NEM) registration process for rooftop solar in Bangladesh under [[Net Metering Guidelines 2025]]. Maintained by [[Netso]] operations.

## Overview

| Item | Detail |
|------|--------|
| **Regulation** | BERC Net Metering Guidelines 2025 |
| **Scope** | Rooftop solar systems up to 1 MW |
| **Settlement** | Monthly net, quarterly surplus at BDT 6.45/kWh |
| **Processing Time** | 30–45 days (typical) |
| **Validity** | As long as system is operational |

---

## The 6-Step Process

### Step 1: Pre-Application Eligibility Check

| Requirement | Status |
|-------------|--------|
| System capacity ≤ 1 MW | Required |
| Grid-connected premises | Required |
| Valid DISCO connection (DESCO/DPDC/BREB) | Required |
| No outstanding DISCO dues | Required |
| Roof ownership or valid lease agreement | Required |

**Required documents at this stage:**
- Customer NID/Passport copy
- Property ownership or lease deed
- Latest DISCO bill
- Single-line diagram (Netso)
- Site layout plan (Netso)
- Equipment datasheets
- Inverter specification
- Structural assessment (required if >50kW)

---

### Step 2: DISCO Application Submission

| DISCO | Submit To | Form |
|-------|-----------|------|
| DESCO | Chief Engineer (Commercial) | Net Metering Application Form |
| DPDC | Chief Engineer | Grid-interactive Solar PV Application |
| BREB | Local PBS office | PBS-specific NEM Application |

**Submission must include:**
- [ ] Duly signed application form
- [ ] NID copy (attested)
- [ ] Property document copy (attested)
- [ ] Latest electricity bill copy
- [ ] Single-line diagram (signed by licensed engineer)
- [ ] Site layout plan
- [ ] Equipment datasheets
- [ ] Inverter anti-islanding certificate
- [ ] Structural stability certificate (if >50kW)
- [ ] Application fee

---

### Step 3: Technical Review + Site Inspection

**DISCO review timeline:**

| Stage | Duration |
|-------|----------|
| Initial screening | 7–10 days |
| Technical review | 10–15 days |
| Site inspection | 15–20 days |
| Final approval | 5–10 days |
| **Total** | **30–45 days** |

**Inspector checks:**
- Roof condition and shading
- Electrical infrastructure (DB capacity, cable routing)
- Safety (earthing, lightning protection)
- Equipment placement (inverter location, accessibility)
- Net meter location

---

### Step 4: Net Meter Installation

- **Meter type:** Bidirectional (import/export), Class 1.0 accuracy, BSTI approved
- DISCO issues, installs and seals meter
- Customer trained on meter reading

---

### Step 5: System Commissioning

**Commissioning tests:**

| Test | Expected Result |
|------|----------------|
| Insulation resistance (megger) | > 1 MΩ |
| Continuity test | < 1 Ω |
| Inverter startup | Normal startup |
| Grid synchronization | Sync achieved |
| Anti-islanding test | Inverter shuts down on grid loss |
| Export test | Export recorded on meter |

**Output:** Commissioning report with photographs + customer sign-off

---

### Step 6: NEM Agreement + Billing Setup

**Sample NEM Bill:**

| Item | Units | Rate | Amount |
|------|-------|------|--------|
| Grid Import | 10,000 kWh | ৳12.50 | ৳1,25,000 |
| Solar Export | 8,000 kWh | ৳6.45 | ৳51,600 |
| **Net Consumption** | **2,000 kWh** | **৳12.50** | **৳25,000** |

> **Monthly savings vs. no solar:** ৳1,00,000

**Key NEM terms:**
- 20-year agreement (matches PPA term)
- Surplus paid quarterly at BDT 6.45/kWh via bank transfer
- Monthly DISCO net metering bill

## SREDA RESCO Registration (Separate Process)

The SREDA RESCO registration is **gate zero** — required before the NEM process begins for [[RESCO Model]] operations.

36-item checklist (per `Netso_SREDA_RESCO_Checklist.md`):
- Company incorporation (RJSC certificate, MoA, Trade License, TIN, VAT)
- Promoter documents (CVs, NID, net worth statements)
- Technical capacity (engineer CVs, certifications, supplier MOUs)
- Financial (audited statements, bank solvency, IDCOL term sheet)
- Pipeline (LOIs, site surveys, preliminary designs)

> **EPC contract + Bangladeshi energy lawyer review required before RESCO submission** (as of April 2026 per Operations log)

## Common Rejection Reasons + Prevention

| Rejection Reason | Prevention |
|-----------------|------------|
| Incomplete documents | Use checklist thoroughly |
| Weak technical team | Hire certified engineers |
| Insufficient financial capacity | Show IDCOL term sheet / bank solvency |
| No project pipeline | Secure 2–3 LOIs before applying |
| Poor business plan | Show realistic 3-year projections |
| Missing attestations | Get all copies properly attested |
