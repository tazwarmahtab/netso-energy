# IDCOL Financing

Infrastructure Development Company Limited (IDCOL) is Bangladesh's primary development finance institution for renewable energy projects. [[Netso]] targets IDCOL debt to finance 80% of each rooftop installation.

## IDCOL at a Glance

| Attribute | Value |
|-----------|-------|
| **Organization** | Infrastructure Development Company Limited (IDCOL) |
| **Type** | State-owned development finance institution |
| **Typical RE financing rate** | 8–10% p.a. (may be lower with GCF subordination) |
| **Maximum debt portion** | 80% of project cost |
| **Maximum tenor** | 15 years for rooftop solar |
| **Minimum DSCR** | 1.25x (1.4x preferred) |
| **Application fee** | BDT [___] (confirm with IDCOL) |
| **Processing time** | 30–60 days for expression of interest; 60–90 days for full application |

---

## Why IDCOL Debt Changes the Math

Without IDCOL debt (100% equity):
- 100kW project cost: ৳87L equity
- IRR: lower, slower payback

**With IDCOL 80% debt:**
- Equity required: only ৳17.4L (20% of project cost)
- Debt service: ৳9.8L/year for 15 years
- DSCR: 1.78x (Year 1) — ample cushion
- Equity IRR: ~22% (vs. ~14% on 100% equity)

## IDCOL Application Process

### Phase 1: Expression of Interest (EOI)
Submit to `info@idcol.org`:
- Company profile
- Proposed project description
- Debt requirement
- Attach: RESCO certificate (or application evidence), signed rooftop PPAs, preliminary CAPEX model

### Phase 2: Full Application
Required:
- Detailed project feasibility study
- 15-year financial model (IRR, NPV)
- Environmental impact screening
- EPC contractor credentials
- DSCR projections

### Phase 3: Disbursement (post-approval)
Milestone-based tranches per project, conditions precedent above.

---

## Post-Financing Compliance

- Annual return filing to IDCOL
- Project progress reports
- Insurance maintained throughout tenor
- PPA revenues routed through IDCOL-designated account
