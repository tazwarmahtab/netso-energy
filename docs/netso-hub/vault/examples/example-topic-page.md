# AI Agents in GTM

## Overview

AI agents in GTM refers to autonomous or semi-autonomous software that performs go-to-market tasks: prospecting, enrichment, content generation, call analysis, deal scoring, and customer engagement. This is distinct from AI-assisted tools (where a human drives and AI suggests) because agents take actions without waiting for human approval on each step.

This topic matters because it's reshaping competitive positioning across the entire GTM stack. Every CRM, sales engagement, and marketing automation vendor is either building agents, acquiring agent companies, or repositioning existing features as "agentic." For GTM teams evaluating tools, separating real agent capabilities from marketing relabeling is critical.

## Subtopics

- [[outbound-automation]] - AI agents that build prospect lists, write sequences, and send outreach autonomously
- [[content-intelligence]] - Agents that analyze content performance and recommend topics, formats, and angles

## Key Players

- [[hubspot]] - Breeze Agents (prospecting and service). Platform incumbent approach: bundled, lower capability, free/cheap.
- [[salesforce]] - Agentforce. Enterprise approach: deep CRM integration, outcome-based pricing ($2/conversation).
- [[outreach]] - Kaia AI agent for call intelligence and follow-up automation.
- [[gong]] - Deal intelligence agents that flag risk and recommend next actions.
- [[clay]] - Data enrichment agents that chain together 50+ data sources automatically.
- [[eleven-labs]] - Voice cloning for AI sales agents. Enabling layer, not a GTM tool itself.

## Current State

- As of April 2026: The market is in the "relabeling" phase. Most vendors have added "agent" to their marketing but the actual autonomy is limited. True agent behavior (multi-step, self-correcting, taking actions) exists in maybe 15-20% of what's being sold as "AI agents." Source: [[2026-02-20-sequoia-ai-agents-market-map]]
- As of March 2026: Salesforce launched outcome-based pricing for Agentforce at $2 per conversation, breaking the per-seat model. This is the first major vendor to tie agent pricing to results rather than access. Source: [[2026-04-08-salesforce-agentforce-pricing]]
- As of March 2026: Outreach's Kaia agent can now autonomously draft follow-up emails based on call transcripts and send them after a 2-hour human review window. If no edits are made, it sends as-is. Source: [[2026-03-01-outreach-kaia-agent-launch]]
- As of February 2026: ElevenLabs launched voice agent APIs that let companies build AI callers with cloned voices. Early adopters are using these for SDR qualification calls. Source: [[2026-04-05-eleven-labs-sales-voice-agent]]
